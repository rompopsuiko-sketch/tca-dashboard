# TCA-Connect

Мобільний застосунок для водіїв вантажівок (журнал змін, паливо, паузи) + дашборд для диспетчера.

## Стек
- **Мобільний застосунок**: React Native / Expo (`main.tsx`, `login.tsx`)
- **Бекенд**: Supabase (таблиці: `shifts`, `fuels`, `events`)
- **Дашборд диспетчера**: `dashboard.html` (окремий статичний файл, деплой на Vercel через GitHub-репозиторій `rompopsuiko-sketch`, живий URL: tca-dashboard-beta.vercel.app)
- **Деплой мобільного застосунку**: EAS Build (`eas build -p android --profile preview`) + EAS Update для OTA-правок JS (`eas update --branch preview --message "..." --platform android` — обов'язково з `--platform android`, бо web export падає через AsyncStorage). Expo-акаунт: mrramzes01.

## Що робить застосунок
Водій: старт/фініш зміни (км, GPS→місто через Nominatim), події завантаження/розвантаження, заправки, паузи (правило 9г/11г відпочинку), генерація PDF-звіту. Дашборд: живий статус усіх водіїв, таймери, PDF-звіти по водію/машині, фільтр по групах (BDF, Ogólna — раніше "DHL", перейменовано в UI, старі рядки в БД лишились group_type='DHL').

## Поточний стан (виправлено і вже задеплоєно, чекає на польове тестування)
- Дублікати змін при подвійному тапі — виправлено (disabled-стан кнопок + перевірка активної зміни в БД)
- "Brak GPS" при втраті мережі — тепер fallback на сирі координати lat,lon
- Зникнення таймера після релогіну — виправлено (restoreState тепер завжди підтягує стан з Supabase по activeShiftId)
- Відкрита проблема: застосунок виходить з логіну при повному закритті через recent-apps (дашборд при цьому показує коректний статус) — не з'ясовано, чи вирішилось попереднім фіксом, чи це окрема проблема. Потребує перевірки на чистій збірці APK.

## Беклог задач (у пріоритеті)
1. Довгі паузи, які "зникають" зі звіту — дні повністю на паузі поза домом не потрапляють у PDF, хоча мають рахуватись для оплати. Два варіанти: (а) детектити дні, повністю вкриті паузою через північ, вставляти синтетичний рядок "Postój — cały dzień"; (б) ширша концепція "виїзд/повернення додому" — рахувати кожен день між ними як день у відрядженні незалежно від активності зміни.
2. Медіа/фото — bulk-експорт фото (зараз завантажуються через CMR/Zdjęcie, але немає масового завантаження в дашборді з фільтром по даті+водію). Потребує роботи з Supabase Storage.
3. PDF-звіт по машині (не по водію) — вибір машини + період, загальний км/літри/L100km між заправками, список водіїв що керували цією машиною за період. UX: кнопка "Pobierz PDF" → вибір "Kierowca / Auto" → відповідний запит даних.

## Відкладено (чекає на рішення боса про пілот)
Двоетапний логін з базою машин/причепів, зміна причепа посеред зміни з геолокацією, фото-чеклист 4 сторони, вкладки "Drivers"/"Fleet", інтеграція з GPS-трекерами боса (платформа поки невідома — треба спитати назву: Wialon/GPS-trace/Navixy/Traccar тощо).
